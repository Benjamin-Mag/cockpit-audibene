Cockpit Audibene

Le panneau latéral qui fait en un clic ce qui en prenait quinze dans Salesforce.

Extension Chrome / Edge — anamnèse, message vocal, mails, prise de RDV Doctolib / Acuitis, suivi des ventes. Rien ne quitte ton poste.

1 · Télécharger

⬇ Télécharger l'extension (.zip) Ouvrir la version web

Dernière version : …. La version web fonctionne sans extension (copier / coller) mais ne dialogue pas avec Salesforce.

2 · Installer (une seule fois)

  1. Décompresse le zip dans un dossier que tu gardes (par ex. Documents\Cockpit Audibene) — ne le supprime pas ensuite.
  2. Ouvre edge://extensions (ou chrome://extensions) et active le Mode développeur (en haut à droite / à gauche).
  3. Clique Charger l'extension non empaquetée et choisis ce dossier.
  4. Sur une fiche Salesforce, appuie sur Ctrl + Shift + Espace (ou clique l'icône bleue) : le panneau s'ouvre à droite.

Mise à jour : remplace le contenu du dossier par celui du nouveau zip, puis ↻ sur la carte de l'extension.

3 · Premier lancement

  1. Choisir mon dossier : prends le dossier où se trouve le data.json de l'ancien générateur de mails — tes modèles sont repris, le fichier reste intact.
  2. Indique ton nom, ton téléphone, et importe si tu veux ton export du suivi des ventes (suivi-ventes-primes-….json).
  3. Quand le navigateur demande l'accès au dossier, autorise-le (c'est la copie de sauvegarde ; tes données sont aussi dans le navigateur).
